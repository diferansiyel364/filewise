# FileWise 🔍

FileWise is a simple Python command-line tool that finds duplicate files using SHA-256 hashing.

## Features

- Detects duplicate files by content, not just filename.
- Scans folders and their subfolders.
- Uses SHA-256 for reliable file comparison.
- Shows duplicate file paths.
- Never deletes files automatically.

## Requirements

- Python 3.8 or newer
